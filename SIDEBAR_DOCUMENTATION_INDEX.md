## 🚀 Getting Started (5 Minutes)

1. **Access the System**
   - Open any page (product, orders, brand, etc.)

2. **Notice the Sidebar**
   - Left side: Fixed professional sidebar
   - Top: Search and notification bar
   - Content: Main page content

3. **Navigate**
   - Click menu items to go to different sections
   - Click arrows to expand/collapse menus
   - Use search for quick lookup

4. **On Mobile**
   - Click ☰ hamburger menu
   - Select your page
   - Sidebar auto-closes

5. **Done!**
   - You're using the new sidebar system
   - Refer to docs for more info
